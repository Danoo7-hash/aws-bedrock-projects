# AWS Bedrock Generative AI Projects

A collection of hands-on projects built using Amazon Bedrock,
LangChain, AWS Lambda, API Gateway, Knowledge Bases, and AgentCore.

## Projects

### 1. Bedrock Q&A System
- Built a question-answering system using Amazon Bedrock and LangChain.
- Deployed the application using AWS Lambda and API Gateway.
- Enables users to submit questions and receive AI-generated answers.

### 2. End-to-End RAG Pipeline
- Implemented Retrieval-Augmented Generation (RAG).
- Used Amazon Bedrock Knowledge Bases and Amazon S3.
- Enables the application to retrieve relevant information from
  a knowledge source before generating responses.

### 3. Google Search AI Agent
- Built an AI agent with Google Search capabilities.
- Used Amazon Bedrock AgentCore for deployment.
- Enables the agent to retrieve information from Google Search
  and use it to answer user queries.

## Technologies Used

- Amazon Bedrock
- Amazon Bedrock Knowledge Bases
- Amazon Bedrock AgentCore
- LangChain
- AWS Lambda
- Amazon API Gateway
- Amazon S3
- Python
- Retrieval-Augmented Generation (RAG)

## Purpose

To develop practical skills in AWS Generative AI,
LLM application development, RAG pipelines, and AI agents.
